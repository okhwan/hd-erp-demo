hd-erp 포트폴리오 데모 (프론트 단독 · 백엔드/DB 없음)

[Vercel 에 올리기]
 방법 1) Vercel CLI
   이 폴더에서:  npm i -g vercel  →  vercel login  →  vercel --prod
   (빌드 설정 질문은 모두 Enter — 이미 빌드된 정적 파일이라 빌드 과정이 없습니다)
 방법 2) GitHub
   이 폴더 내용만 새 저장소에 올리고 Vercel › Add New Project › 그 저장소 선택 › Framework Preset = Other › Deploy

[동작 방식]
 · 로그인 없이 바로 메인화면이 열립니다.
 · 화면의 모든 조회는 mock-api.js 가 mock-data.json(가상 데이터)으로 답합니다.
   검색어·기간·상태 필터·정렬·페이지 넘김·자동완성은 실제 서버와 같은 규칙으로 계산됩니다.
 · 날짜는 접속한 날 기준으로 자동으로 옮겨져서, 언제 들어와도 오늘·이번 달 데이터가 보입니다.
 · 등록·수정·삭제는 확인창까지 정상으로 나오지만 실제로 저장되지는 않습니다 (안내 문구가 잠깐 뜸).
 · 회사명·주소·사업자번호·로고는 모두 가명(데모자동문)으로 바뀌어 있습니다.
